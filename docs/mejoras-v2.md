# Mejoras propuestas para la versión 2

1. Autenticación de usuarios.
2. Asignación de responsables y fechas límite, con filtros y búsqueda.
3. Base de datos persistente (PostgreSQL), porque el almacenamiento del plan gratuito de Render es efímero.
4. Notificaciones de tareas próximas a vencer.
5. Reportes de productividad.
